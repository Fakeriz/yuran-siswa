## Perubahan

1. Kontras: token landing terang #005FCC dengan teks #FFFFFF (5,98:1); gelap #8CBEFF dengan teks #122744 (7,81:1). Badge Demo juga menggunakan pasangan solid ini. Token dibatasi CSS module agar dashboard tidak berubah.
2. Konsistensi: aksi demo memakai aksen biru dan focus outline. CTA utama netral hitam dipertahankan sebagai hierarki primer; hijau/merah hanya untuk makna status yang sudah ada. Varian default komponen demo mempertahankan gaya halaman login.
3. Bahasa: label Staf, Orang Tua, Coba Portal, dan Juli konsisten dengan panduan Bahasa Indonesia. Nilai role `staff`/`orang_tua`, email demo, kata sandi demo, serta URL tetap sama. Label demo bersama ikut konsisten di halaman login.
4. Hero: paragraf menjadi 17 kata; padding atas desktop 96px menjadi 56px, gap contoh portal 56px menjadi 32px, dan H1 desktop 72px menjadi 60px. Informasi tentang ketiga peran tetap ada. Tinggi akhir perlu diukur pada preview browser.
